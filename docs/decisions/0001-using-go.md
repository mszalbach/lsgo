# Using Go

## Context and Problem Statement

The project is a command-line and web-facing tool, and the author wants to improve their Go skills.

## Considered Options

* Implement the project in Go
* Implement the project in Java
* Implement the project in Python

## Decision Outcome

Chosen option: "Use Go", because go fits the project’s needs well, is widely used for command-line tools and server-side workloads, and keeps the implementation straightforward and idiomatic.

### Consequences

* Good, because the codebase and workflow follow Go conventions and build tooling.
* Good, because the project is well suited to the author’s learning goals and common deployment patterns.
* Bad, because go-specific conventions and tooling choices may limit contributors who are more familiar with other ecosystems.
