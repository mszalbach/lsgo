# Introduction

The architecture documentation takes a pragmatic approach. 
It uses a slimed down [arc42](https://arc42.org/), [C4 diagrams](https://c4model.com/) and [ADRs](https://adr.github.io/madr/)

It wil lfocus on these arc42 secitons:

| Essential Section             | What It Replaces in Full arc42 | Core Focus                                             |
| :---------------------------- | :----------------------------- | :----------------------------------------------------- |
| Context & Scope               | Section 3                      | External systems and interfaces                        |
| Building Block View           | Section 5                      | Structure of source code                               |
| Runtime View                  | Section 6                      | Important runtime scenarios                            |
| Deployment View               | Section 7                      | Hardware, infrastructure and deployment                |
| Architecture Decisions (ADRs) | Section 9                      | Why specific tech, patterns, or frameworks were chosen |
| Risks and Technical Debt      | Section 11                     | Known problems and risks                               |
